# Mutiny

> Mutiny is a GTM (go-to-market) assistant built for customer-facing work. It is a vertical AI platform for B2B revenue teams that generates on-brand customer-facing assets (deal rooms, pitch decks, business cases, ABM campaigns, comparison pages, meeting recaps) and automates repetitive sales and marketing workflows through an agent/skill/routine framework. Mutiny connects to CRM and GTM systems and exposes a hosted Model Context Protocol (MCP) server so agents like Claude and ChatGPT can create, browse, and publish assets directly in conversation.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Mutiny surface and the artifacts in this repository. Mutiny does not publish a general-purpose REST API or OpenAPI; its programmatic entry point is the hosted MCP server.

## Agent access (MCP)
- [Setting up the Mutiny MCP](https://help.mutinyhq.com/articles/5947474042-setting-up-the-mutiny-mcp): Hosted MCP server at https://mcp.mutinyhq.com/mcp (HTTP transport, OAuth 2.0).
- [Connecting Mutiny to Claude](https://help.mutinyhq.com/articles/5003451538-connecting-mutiny-to-claude): Create assets, browse templates, manage and publish content library from Claude/ChatGPT.
- OAuth authorization server: https://mcp.mutinyhq.com/.well-known/oauth-authorization-server
- Scopes: read_asset_groups, create_asset_groups, publish_asset_groups, read_library_content, manage_library_content
